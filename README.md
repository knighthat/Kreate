# ✨ Features

- **Multiple sources**: Supports **YouTube Music**, **OpenSubsonicAPI**, and **local songs**
- **Lyrics**: synced and plain lyrics from several sources (**BetterLyrics**, **LyricsPlus**,
  **LRCLIB** and others)
- **Downloads**: offline songs, a download queue (pause, resume, retry, cancel)
- **Song cache**: streamed songs are kept per quality and can be replayed offline.
- **Radio**: songs similar to a given song.
- **Sleep timer**: a countdown or "until the song ends", +/-, pause, stop, and restart buttons in
  notification.
- **History**: grouped by day, week and month, with date ranges and source filters.
- **Android Auto**: supports browse, playback, voice search.
- **Statistics**: all time or this month, with top songs, albums and artists, time per source, and
  charts by day, hour and weekday.
- **Sharing**: YouTube links, OpenSubsonic share links, or the local file itself.
- **Equalizer**: opens the system audio effects panel.
- **Loudness normalization**: evens out volume between songs. Local songs are also supported
- **Stream quality**: separate Wi-Fi and mobile settings for each source.
- **Open with**: plays audio files and music.youtube.com links opened from other apps.
- **MusicBrainz**: pulls information such as first release, ISRCs, genres and releases.
- And many more

# 🤝 Contributing

## To improve functionalities

Contributions are welcome! To develop new features or fix bugs, please fork the repository and open
a pull request.

**For more details, please refer
to** [the documentation](https://kreate.knighthat.me/dev/getting_started).

## To translate app

To **translate** or **improve a translation**, **fix typo**, or to **request new language**.

[![Translated with Crowdin](https://badges.crowdin.net/badge/light/crowdin-on-dark.png)](https://translate.kreate.knighthat.me/project/kreate)

## To write documentation

**To help others understand the app, please
visit** [knighthat/Kreate-docs](https://github.com/knighthat/Kreate-docs) repository.

## If you are good at designing

UI/UX designers are welcome!

**Submit your designs
by** [opening a ticket](https://github.com/knighthat/Kreate/issues/new?template=feature_request.yaml)
